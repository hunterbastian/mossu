# Mossu Concept Art

Curated reference art for Mossu's visual direction.

Use this folder for durable art references that should survive beyond local `output/` captures. Keep generated screenshots, QA artifacts, and one-off experiments in `output/`; promote only the references that are useful for future implementation decisions.

## Current Boards

- `floating-island/` - whole-island silhouette, cliffs, ocean-below read, waterfalls, sky, and terrain massing.

## Reference Rules

- Record what to borrow and what to avoid next to each image.
- Do not treat a reference as a literal paintover target.
- Prefer implementation notes that map to Mossu systems: terrain contour, shell/underside, water, sky, foliage, route readability, UI/title composition.
- Keep runtime assets in `public/` only when they are actually loaded by the game.
